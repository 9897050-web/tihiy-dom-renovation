# Тихий дом

Адаптивный демонстрационный сайт нового бизнеса по ремонту квартир. Отдельный проект, не связан с другими репозиториями владельца.

## Запуск

Статический сайт без сборки. Запустите `python -m http.server 4181` в этой папке или разместите её содержимое на GitHub Pages (ветка main, корень).

## Что работает

- Навигация, мобильное меню, раскрывающиеся ответы.
- Выбор формата работ, площади, состояния и пожеланий.
- Расчёт по двум ставкам пользователя, включая выбранный резерв; проверка диапазонов ввода.
- Подготовка обращения, копирование и скачивание текстового плана.

## Границы демонстрации

«Тихий дом» — рабочее название. Город не задан. Телефон и Telegram являются явно обозначенными заглушками, а не контактами реальных людей. Отправка заявок и аналитика не подключены. Данные формы остаются в памяти страницы. Цены компании, гарантии, отзывы и выполненные объекты не выдумываются. Состав услуг и этапы предложены для утверждения владельцем.

Перед коммерческим запуском: подтвердить название, географию, услуги и условия; заменить контакты; подключить согласованный канал заявок; добавить сведения об исполнителе и соответствующую фактической обработке данных политику.
